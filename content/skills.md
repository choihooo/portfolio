## 기술 스택

### Frontend Core

| 기술 | 수준 | 설명 |
|------|------|------|
| **React** | 상급 | UI Kit, 어드민, 데스크톱 앱, 해커톤 서비스, 디자인 시스템 구현 경험 |
| **Next.js** | 상급 | App Router, API Route, 인증/보호 라우트, 추천 탭, 정적/동적 웹 서비스 구현 |
| **TypeScript** | 상급 | strict mode 전환 기반 마이그레이션, 타입 안정성 개선, 패키지 타입 정의 구성 |
| **JavaScript** | 상급 | 레거시 JSP/jQuery 코드베이스 대응, React/Vite 기반 제품 구현 |
| **HTML/CSS** | 상급 | 반응형 레이아웃, 접근성, SEO, Core Web Vitals 개선, Tailwind 기반 UI 구현 |

### Styling & UI

| 기술 | 수준 | 설명 |
|------|------|------|
| **Tailwind CSS** | 상급 | 제품 UI, 랜딩 페이지, 디자인 시스템 문서, 반응형 화면 구성 |
| **Storybook** | 중급 | 디자인 시스템 컴포넌트 문서화와 테스트 러너 기반 검증 |
| **Vanilla Extract** | 중급 | 디자인 시스템 패키지의 스타일 구조와 빌드 파이프라인 구성 |
| **Figma / Design Tokens** | 중급 | Token Studio 기반 토큰 파이프라인, 컴포넌트 시안 분석, UI 자산화 |

### State & Data

| 기술 | 수준 | 설명 |
|------|------|------|
| **Zustand** | 상급 | 데스크톱 앱과 게임/해커톤 서비스에서 도메인별 상태 분리 및 persist 적용 |
| **TanStack Query** | 중급 | API 접근 모듈화, 캐시 무효화, 재검증 전략 |
| **Recoil** | 중급 | 운영형 어드민에서 atom/selector 기반 센터 데이터 상태관리와 캐싱 적용 |
| **Drizzle ORM / Supabase** | 중급 | study-admin 추천 시스템의 데이터 모델과 API 연결 |

### AI / Search / Automation

| 기술 | 수준 | 설명 |
|------|------|------|
