## 소개

최호는 TypeScript 기반 프론트엔드와 제품 구현 경험을 쌓아온 프론트엔드 개발자입니다. 어드민 서비스, 디자인 시스템, Electron 데스크톱 앱, AI 기반 웹 서비스를 만들며 사용자가 헷갈리지 않는 흐름과 팀원이 쓰기 편한 구조를 함께 고민해왔습니다.

아이디어를 실제로 동작하는 제품으로 완성하는 과정에 관심이 많고, 빠르게 만들되 검증과 기록을 남기는 방식을 선호합니다. 최근에는 AI를 단순 호출 API로 붙이는 데서 끝내지 않고, 추천 이유 UI, 검색 근거 표시, agent workflow, 백그라운드 자동화처럼 사용자가 믿고 쓸 수 있는 제품 흐름으로 연결하는 데 집중하고 있습니다.

## 어떤 개발자인가요?

최호는 화면 구현과 구조 개선을 분리해서 보지 않습니다. 컴포넌트 재사용성, 상태 책임, 타입 안정성, 접근성, 반응형 품질, 문서화를 함께 정리해야 제품이 오래 유지된다고 봅니다.

아이겐코리아에서는 운영 중인 어드민 서비스의 TypeScript 마이그레이션, 다국어 검증 자동화, 센터관리 시스템의 하드코딩 제거 같은 프론트엔드 플랫폼 개선을 수행했습니다. 야몬에서는 UI Kit와 컴포넌트 쇼케이스, Codex/agent 기반 CLI workflow, Electron 기반 AI 검색 제품을 다루며 프론트엔드와 AI 제품 개발 흐름을 함께 경험했습니다.

## 개발 철학

- **사용자 흐름 중심**: 인증, 온보딩, 추천, 검색 결과처럼 사용자가 다음 행동을 결정해야 하는 지점의 상태와 근거 표시를 중요하게 봅니다.
- **팀이 쓰기 쉬운 구조**: UI Kit, 디자인 시스템, i18n, Storybook, 문서화처럼 팀원이 반복해서 쓰는 자산을 정리하는 데 강점이 있습니다.
- **측정 가능한 개선**: 빌드 시간, Lighthouse, 토큰 비용, 추천 탭 클릭률 같은 지표로 개선 전후를 확인하려고 합니다.
- **AI를 제품 흐름으로 연결**: 임베딩, 검색, agent workflow를 사용자 화면과 운영 흐름에 연결하고, 추측보다 근거와 fallback을 명확히 두는 방식을 선호합니다.

## 현재 관심사

최근 관심사는 AI/AX 프론트엔드, 디자인 시스템, 데스크톱 앱, 웹 성능과 접근성입니다. 특히 RAG나 추천 시스템을 단순히 “AI 기능”으로 보여주는 것보다, 사용자가 왜 그 결과를 받아야 하는지 이해할 수 있는 UI와 운영 가능한 데이터 갱신 구조를 만드는 데 관심이 있습니다.
